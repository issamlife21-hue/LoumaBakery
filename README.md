# Louma Bakery (v2)

Minimal [Astro](https://astro.build) project. TypeScript `strict`, no UI framework.

## Prerequisites

- Node.js >= 22.12.0
- npm

## Install

```bash
npm install
```

## Run

| Command           | Action                                      |
| ----------------- | ------------------------------------------- |
| `npm run dev`     | Start the dev server at `localhost:4321`    |
| `npm run build`   | Build the production site to `./dist/`      |
| `npm run preview` | Preview the build locally, before deploying |

## Deploy

Hosted on Netlify. Pushes to `main` trigger a deploy once the repo is connected
in the Netlify dashboard.
